# ChatGPT 移动端体验对标基准

本轮选用 **ChatGPT iOS** 作为轻聊 AI 的功能与交互参考，但不复制其品牌、视觉或完整功能集。轻聊 AI 保持“本机、多 AI、无登录”的产品定位。

## 可采纳的原则

1. 将近期对话放在易于打开的侧边栏或抽屉中，并让新建对话成为低成本的首要操作。
2. 为历史记录提供明确、可逆的管理操作：至少包含检索、重命名与删除确认。
3. 让长记录可被快速定位，而不是只按时间线浏览。
4. 让输入状态与配置状态明确可见；未配置模型时必须给出清晰下一步。

## 本轮优先改进

| 优先级 | 改进 | 原因 |
| --- | --- | --- |
| P0 | 本地会话搜索与零结果提示 | 多 AI 与本地会话增多后，侧边栏单纯列表不易找回旧对话。 |
| P0 | 会话重命名、删除确认与更清晰的操作入口 | 避免误删，并允许整理本地历史。 |
| P1 | 模型配置连通性检查与具体错误提示 | 浏览器直连模型时，Base URL、CORS 和 API Key 的失败应可理解。 |
| P1 | 输入草稿的本地保存与恢复 | 手机切换页面或误触返回时减少文字丢失。 |
